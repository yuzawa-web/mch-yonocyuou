| **ご利用料金** | 改定があるため。載せるなら「いつ時点の金額か」を明記し、更新の担当を決める |

## 計測のためのお願い

- ボタン・リンクの `id` は**消さないこと**（GA4で押された回数を数えるため）
  `btn-tel` `btn-visit`（1枚目）／`btn-tel-2` `btn-visit-2`（最後のご相談）
  `btn-tel-bar` `btn-visit-bar`（**画面下のバー＝最重要**）
  `btn-pdf-pamphlet`（パンフレットのダウンロード）
  `btn-recruit-header` `btn-recruit-footer` `btn-instagram` `btn-org` `btn-map`
- 採用リンクの `?utm_...` も**消さないこと**
- `tel:` のクリックはGA4の自動計測では数えられません（タグマネージャー等の設定が別途必要）
