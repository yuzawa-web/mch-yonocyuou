# メディカルケアホーム与野中央 サイト（1枚もの）

2026年9月9日 作成／**2026年9月11日 更新（第4版）**

**色を、医療法人博滇会のカラーコード一覧に合わせました。**
MAIN01 博（深紅）／MAIN02 滇（深藍）／SUB01 暮らし（稲）／SUB02 育つ（若葉）と、
展開色（ピンク・水色・紫・黄色）を使っています。くわしくは下の「色の決めごと」。

節の見出しは「＼ 小さな一行 ／＋中央の見出し＋黄色い手描き線」でそろえ、
カードは5色を順番に当てています。
おすすめポイントは、左上の色の三角に番号・アイコン・斜めに切った写真の形です。

**5つのおすすめポイントが、このページの中心です。**
各カードの下の「くわしく見る ＋」を押すと、**そのカードの中で**くわしい内容が開きます
（開くとカードが横いっぱいに広がります）。

**くわしい内容は、そのカードの中にしかありません。**
同じ文章がページの別の場所にもある、という状態を作らないためです
（2か所にあると、必ずどちらかが古くなります）。

## 色の決めごと（博滇会のカラーコード一覧より）

| ボタン・最後のご相談の地・見出し | `#1E4068` | 深藍1（滇） |

| 枠線 | `#E2D9C6` | 稲2 |
| カード1 | `#9DB899` | 若葉2（育つ） |

本番として `hakushinkai.jp` に置いたときに、サイト側のアナリティクスが読み込まれ、
