# メディカルケアホーム与野中央 サイト（1枚もの）

2026年9月9日 作成／**2026年9月11日 更新（第4版）**

**色を、医療法人博滇会のカラーコード一覧に合わせました。**
MAIN01 博（深紅）／MAIN02 滇（深藍）／SUB01 暮らし（稲）／SUB02 育つ（若葉）と、
展開色（ピンク・水色・紫・黄色）を使っています。くわしくは下の「色の決めごと」。

節の見出しは「＼ 小さな一行 ／＋中央の見出し＋黄色い手描き線」でそろえ、
カードは5色を順番に当てています。
おすすめポイントは、左上の色の三角に番号・アイコン・斜めに切った写真の形です。

**5つのおすすめポイントが、このページの中心です。**
各カードの下の「くわしく見る ＋」を押すと、**そのカードの中で**くわしい内容が開きます
（開くとカードが横いっぱいに広がります）。

### くわしい内容は「ポップアップ」で開きます（2026-09-17 変更）

トイロFESのサイトの「8つの体験プログラム」と同じ形にしました。
**「くわしく見る」を押すと、画面の真ん中に大きく開きます。**

| | |
|---|---|
| 開く | カードの下の「くわしく見る」を押す |
| 閉じる | **右上の × ／ 背景の暗いところ ／ Escキー ／ 中身のいちばん下の「とじる」** |
| 1〜5を行き来 | 下の「**前へ／次へ**」（5の次は1に戻ります）。広い画面では左右の丸い矢印も出ます |
| キーボード | ← → で移動、Esc で閉じる |

色・番号・見出しは、**開いたポイントのものに自動で切り替わります**（1は若葉、3は黄色…）。

**⚠️ 中身は1か所にしかありません。**
折り畳みの中にあるものを、開くときにポップアップへ「移してくる」作り方にしています。
同じ文章を2か所に置いていないので、**直すときは1か所だけ**です。

**この仕組みが動かない端末では、いままでどおりの折り畳みとして開きます。**
（下の「開け閉めの見え方」は、そのときの見え方です）

### 開け閉めの見え方（2026-09-11 改良・折り畳みとして開いたときの話）

「閉じ方がわかりにくい」というご指摘を受けて、**3つ**直しました。

| | 直したこと |
|---|---|
| 1 | **文字が変わります。** 閉じているとき「お部屋と設備を、くわしく見る」→ 開くと「**とじる**」 |
| 2 | **帯の色が反転します。** 開くと帯が濃い色・白文字になり、「いま開いている」が一目でわかります |
| 3 | **中身のいちばん下にも「↑ とじる」ボタン**を置きました。長い内容を読み終えた場所で閉じられます（閉じるとカードの先頭に戻ります） |

＋／− の印も、白い丸の中に入れて「押すところ」に見えるようにしています。

**くわしい内容は、そのカードの中にしかありません。**
同じ文章がページの別の場所にもある、という状態を作らないためです
（2か所にあると、必ずどちらかが古くなります）。

## 問い合わせフォームのURLに付けた「印」（2026-09-14）

法人共通フォームは、どの施設から来た相談なのか区別がつきません。
そこで、**このページから飛ぶリンクだけに印を付けました。**

```
https://hakushinkai.jp/contact/?from=mch-yono&place=bar
                               ↑どの施設から   ↑どのボタンから
```

`from` は全部 `mch-yono`（与野中央）で共通。`place` はボタンごとに変わります。

| place | どのボタン |
|---|---|
| `fv` | 1枚目の「見学・入居のご相談」 |
| `bar` | **画面下のバー**（最重要） |
| `cta` | 最後の「まずは、ご相談ください。」 |
| `footer` | フッターの白いカード |
| `katachi` | **4つのかたちの下の大きなボタン**（2026-09-17。もとの4本を1つにまとめました） |

### ★なぜ `utm_source` を使わないのか（大事なところ）

採用リンクには `?utm_source=mch-yono` を付けています。**あちらは正しい使い方です**
（`arwrk.net` という**別のサイト**へ送るため）。

しかし**同じサイトの中のリンクに `utm_` を付けると、アナリティクスが壊れます。**
GA4は `utm_` を見つけると「新しいお客さんが、外から来た」と判断して**セッションを切り直す**ため、

- 「Googleから来た人が、与野中央を読んで、問い合わせた」という**つながりが切れる**
- 問い合わせが、ぜんぶ「mch-yono から来た」ことになり、**本当の入口がわからなくなる**

`from` `place` という**utm以外の名前**にしておけば、セッションは切れず、
アドレスの文字としてだけ記録されます。これが目的にかなっています。

### 見かた（GA4）

**レポート → エンゲージメント → ページとスクリーン**を開き、
表の左上のプルダウンを「**ページ パスとクエリ文字列**」に変えます。すると

```
/contact/?from=mch-yono&place=bar      12
/contact/?from=mch-yono&place=footer    5
/contact/?from=mch-yono&place=fv        3
```

のように、**どのボタンが問い合わせページまで連れて行けたか**が並びます。
検索窓に `from=mch-yono` と入れれば、与野中央の分だけ見られます。
ほかの施設ページにも同じ印を付ければ、施設ごとの比較もできます。

**⚠️ これは「フォームを開いた数」で、「送信した数」ではありません。**
送信まで数えるには、法人サイト側のフォームに手を入れる必要があります。

### 次の一手：フォーム自体に施設名を入れる

いまのままだと、**届いたメールを見ても、どの施設への相談かわかりません。**
フォームに見えない項目（hidden）を1つ足して、`from` の値をそこに写せば、
**届いたメールに「mch-yono」と入る**ようになります。
Elementorのフォーム設定でできるはずですが、実際の画面を見て確かめる必要があります。
